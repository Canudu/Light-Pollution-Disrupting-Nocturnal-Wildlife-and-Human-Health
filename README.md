# Light-Pollution-Disrupting-Nocturnal-Wildlife-and-Human-Health

Artificial lighting at night confuses migratory birds, interferes with firefly communication, and disrupts the feeding patterns of bats. It also suppresses human melatonin production, affecting sleep quality. Simple changes—such as shielding outdoor lights, using warm-toned LEDs, and installing motion sensors—can mitigate these effects. Dark-sky initiatives preserve both ecological integrity and our view of the stars ✅✅✅✅
